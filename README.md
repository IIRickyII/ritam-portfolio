# Ritam Biswas — Portfolio

Personal portfolio for Ritam Biswas, a nanotechnology researcher and data
scientist working across semiconductor technology, MEMS, space plasma physics,
and computational science.

## Run locally

```bash
npm install
npm run dev
```

The local site is served at the URL printed by Vite.

## Validate and deploy

```bash
npm run lint
npm run build
npm run deploy
```

Deployment publishes the production build to the repository's `gh-pages`
branch for GitHub Pages.
